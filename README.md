# wynne-legal

Rechts- und Supportseiten der App **Wynne** (iOS/Android, `com.creaiter.wynne`).

Dieses Repository ist öffentlich, weil App Store und Play Store eine frei
erreichbare Datenschutzerklärung verlangen. Der App-Quellcode liegt getrennt
und privat unter `Ben-Apps/wynne`.

Die Seiten werden über GitHub Pages ausgeliefert. Quelle der HTML-Dateien ist `docs/site/build_legal.py` im App-Repo; hier nur das Ergebnis. Quelle ist `main`, Wurzel.
`.nojekyll` verhindert, dass Jekyll die Dateien umschreibt.

| Datei | Zweck |
|---|---|
| `privacy.html` | Datenschutzerklärung (EN + DE) |
| `terms.html` | Nutzungsbedingungen (EN + DE) |
| `index.html` | Startseite |
| `support.html` | Support und häufige Fragen (EN + DE) |
| `delete-data.html` | Datenlöschung — Wynne hat keine Konten; Play-Angabe „Datenlöschung" (EN + DE) |
| `content_pack_v1.json` | optionales Inhaltspaket der App |
